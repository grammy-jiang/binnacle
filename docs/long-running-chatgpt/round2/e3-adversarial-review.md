# E3 — Round 2 adversarial review

Status: **E3 complete, 2026-09-29.** Adversarial review of `e1-contract-draft.md`, grounded in the current read-only checkout. No product code was changed and no commit was made.

## Verdict

Draft v1 should not freeze unchanged. Findings: **3 BLOCKER / 6 CHANGE / 5 NOTE**.

Top three:

1. **BLOCKER — tail reseeding loses unseen history.** A clipped ordinary tail followed by `next_after = EOF` silently skips everything omitted before EOF.
2. **BLOCKER — UTF-8 suffix handling can loop forever.** An incomplete trailing multi-byte sequence makes “stop before it”, raw-byte `has_more`, and guaranteed progress mutually inconsistent; a terminal truncated sequence can make the loop permanent.
3. **BLOCKER — the cursor is not job-bound.** A valid integer cursor from job A can be applied to job B and silently skip or replay B whenever the offset is in range.

The smallest coherent freeze is: do not mint a consumption cursor from ordinary tail mode; define exact incomplete/invalid UTF-8 byte-consumption semantics; and bind resumable cursors to job identity (preferably with a version/generation path).

## Current-code grounding

- `job_status` is stateless and currently reads lifecycle from disk before reading output.
- Durable storage is `meta.json` plus append-only `out.log`.
- `jobs._prune()` spares running jobs but may delete older terminal/unknown directories when a new job reserves a retention slot.
- The managed job owner is a sibling service, so tunnel/MCP control-plane restarts do not own command processes.
- `binnacle-jobs.service` uses `KillMode=control-group`; `recover_previous_owner()` finalizes unfinished v2 records as `owner_restart`, `host_reboot`, or `stop_requested`.
- The current whole-log storage helper maps `OSError` to empty bytes. Cursor mode must not inherit that behavior for a prune/read race.

## Cross-cutting contract changes before E4 freeze

These are minimum deltas, not a rewrite:

1. **Cursor fields only in cursor mode.** Do not return `next_after` from ordinary tail mode; preserve the old no-`after` payload exactly.
2. **Bind cursor identity.** A resumable cursor must carry or require job identity; leave room for a generation before future rotation/replacement.
3. **Define byte/UTF-8 progress precisely.** Pending incomplete suffix while running is not “more readable text”; terminal invalid/incomplete bytes are consumed with replacement so terminal drain can finish.
4. **Define range identity for retries.** Echo `from_after` or equivalent so replayed ranges are publicly recognizable.
5. **Define read/prune atomicity and expiry.** A cursor call already reading cannot be invalidated into an empty success by prune; later pruned cursors get an explicit expiry/unknown outcome. Recovery is retention-bounded unless policy changes.
6. **Qualify interruption guarantees.** Cursor recovery begins once `job_id` is known; initial lost `run_command` results and embedded-owner `unknown` behavior remain separate gaps unless brought into v1.

## E4 recommendation

Proceed to E4 only after the three BLOCKER semantics are resolved in the contract text. The storage/helper split remains sound, but I-A must not freeze a `read_log_range` contract that treats a disappeared file as empty success, and I-B should not freeze tail-mode `next_after` or a naked cross-job integer cursor.
